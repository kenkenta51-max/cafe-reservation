## 公開前に必ず対応すること

- **クラウドファンディングのキャプチャ画像を、実物に差し替える**

  `src/index.html` セクション7には現在 `assets/original/nagi_cf_summary_mock.png`
  （`public/images/cf-summary-*`）を掲載しているが、これは**架空データによる仮素材**
  であり、サンプル制作用のモックアップである。画像内に「本画像はサンプル制作用の
  架空データによるイメージです。特定の支援プラットフォームの画面を再現したもの
  ではありません」という注記が入っており、**この注記は一切加工・トリミングして
  いない**（今後も加工しないこと）。

  この仮素材は、支援者512名・支援総額8,942,000円という実績数値の**出典としては
  機能しない**。`docs/02_strategy.md §5` の「CF公式ページのキャプチャを出典として
  明記して使用可」という位置づけは変更されておらず、**公開前には実物の
  クラウドファンディングページのキャプチャへの差し替えが必須**である。
  差し替え箇所は `src/index.html` 内の `TODO［公開前に必須］` コメントを参照。
- **カラバリ3色の商品写真を、実物に差し替える**

  `src/index.html` セクション3には現在AI生成のサンプル画像を3枚（ディープグリーン・
  ミストグレー・サンドベージュ）掲載しているが、いずれも**実物の商品写真ではない**。
  特に「ディープグリーン」は実測RGB値`(177,157,138)`で緑の要素を含まない暖色系の
  グレージュであり、`inputs/02_client_materials/nagi_company_product_profile.md`
  に記載された正式な色名と写真の見た目が一致していない。3枚とも
  「サンプル画像（実物と色味が異なります）」の注記を付けているが、**公開前には
  3色とも実物の商品写真への差し替えが必須**。差し替え箇所は `src/index.html` 内の
  `TODO［公開前に必須］` コメントを参照。
- **「3つの特徴」セクションの写真を、実物に差し替える**

  現在使用している `nagi_feature_app.png`（タンク取り外しの写真）・
  `nagi_feature_quiet.png`・`nagi_feature_tank.png`（アプリ操作の写真）はいずれも
  サンプル画像。支給時のファイル名と実際の写真内容が入れ替わっていたため、
  `src/index.html` では**写真の内容に合わせて用途を入れ替えて使用している**
  （`nagi_feature_tank.png`→①スマホ操作、`nagi_feature_app.png`→③タンク分解）。
  実物の撮影データに差し替える際は、ファイル名だけで機械的に対応させず、
  必ず写真の内容を確認すること。

## 案件フォルダの構成ルール

**`docs` は設計文書（Markdown）専用、HTML/CSS などの実装コードはすべて `src` に置く。**

- `inputs/01_hearing` : クライアントヒアリング内容（議事録・要望メモなど）を格納
- `inputs/02_client_materials` : クライアント支給の原稿・画像・ロゴ・ブランド資料を格納
- `inputs/03_reference_sites` : 参考LP・競合サイトのスクリーンショットやURLメモを格納
- `docs` : 要件定義・訴求設計・参考サイト分析・デザインシステム・構成案・原稿（すべてMarkdown）
- `rules` : デザインルール（配色・フォント・トンマナ等）・コーディングルールを格納
- `assets/original` : 未加工の元素材
- `assets/optimized` : 書き出し・圧縮済みの最終素材
- `src` : LP実装のソースコード
  - `src/index.html` : **LP本体**。ここに追記して育てる
  - `src/wireframe.html` : ワイヤーフレーム（構成確認用）
  - `src/preview/` : PC/スマホを並べて確認する自己完結ビューア（共有可）
- `public/images` : 公開用に最適化済みの画像（ビルド成果物）
- `qa` : QAチェックリスト・テスト結果・修正依頼リスト
- `delivery` : クライアント納品物一式
