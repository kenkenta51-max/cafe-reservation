## セクション1：ヒーロー（興味）

| 項目 | 内容 |
|---|---|
| セクション名 | ヒーロー |
| 目的 | 第一印象で「もっと見たい」と思わせる。デザイン性の高さを一瞬で伝える |
| ユーザーへ伝える内容 | 商品の世界観と、価値提案の核（デザインと手間のなさの両立） |
| 必要な見出し | メインメッセージ案A「置いているだけで、部屋が整う加湿器。」（02_strategyの推奨案） |
| 必要な証拠・画像・数値 | 商品単体写真（白背景）、価格12,800円（税込）の明示 |
| CTAの有無 | あり（「NAGIを購入する」） |
| 次のセクションへつなぐ理由 | 世界観だけでは「自分に関係あるか」が分からないため、次でユーザー自身の悩みに接続する |

## セクション2：悩みの提示（共感）

| 項目 | 内容 |
|---|---|
| セクション名 | こんな悩みはありませんか |
| 目的 | ターゲットの悩みを言語化し、「自分のことだ」と思わせる |
| ユーザーへ伝える内容 | 乾燥による喉・肌の不調、市販加湿器の生活感、手入れの手間という3つの悩み |
| 必要な見出し | 「加湿器を置きたいのに、置けない理由がある。」 |
| 必要な証拠・画像・数値 | 悩みを表す簡潔なテキスト3項目（01_requirements「ユーザーの悩み」に準拠） |
| CTAの有無 | なし |
| 次のセクションへつなぐ理由 | 悩みを共有した直後に「では何が解決してくれるのか」という期待が生まれるため、解決策の提示に接続する |

## セクション3：価値提案・解決策の理解①（解決策の理解）

| 項目 | 内容 |
|---|---|
| セクション名 | NAGIが解決すること |
| 目的 | 前セクションの悩みに対して、NAGIが何を提供するのかを一言で示す |
| ユーザーへ伝える内容 | 「デザインを妥協せず、手間なく最適な湿度を保てる」という価値提案そのもの |
| 必要な見出し | メインメッセージ案C「デザインも、湿度管理も、妥協しない。」（02_strategyでページ中盤向けと位置づけた案） |
| 必要な証拠・画像・数値 | ミニマルデザイン3色展開であることの明示 |
| CTAの有無 | なし |
| 次のセクションへつなぐ理由 | 価値提案を「具体的に何ができるのか」で裏付ける必要があるため、機能紹介に接続する |

---

## セクション4：主な特徴（解決策の理解②）

| 項目 | 内容 |
|---|---|
| セクション名 | 5つの特徴 |
| 目的 | 価値提案を具体的な機能に分解し、納得感を持たせる |
| ユーザーへ伝える内容 | ①スマホ遠隔・自動制御　②20dB以下の静音設計　③工具不要の抗菌タンク　④ミニマルデザイン3色展開　⑤満水・空焚き自動停止（01_requirements準拠） |
| 必要な見出し | 「暮らしに、静かに寄り添う5つの工夫。」 |
| 必要な証拠・画像・数値 | 各特徴のアイコン、静音値20dB以下、タンク容量2.5L・連続約20時間運転 |
| CTAの有無 | なし |
| 次のセクションへつなぐ理由 | 「スマホ遠隔・自動制御」という機能は、実際の操作イメージが伴わないと伝わりにくいため、アプリ画面の紹介に接続する |

## セクション5：アプリ連携（解決策の理解③）

| 項目 | 内容 |
|---|---|
| セクション名 | スマホひとつで、湿度管理を |
| 目的 | 「手間なく管理できる」という価値を、操作イメージで具体的に伝える |
| ユーザーへ伝える内容 | アプリで湿度・稼働スケジュールを自動管理できること |
| 必要な見出し | 「湿度のことは、スマホに任せる。」（02_strategy案B） |
| 必要な証拠・画像・数値 | 実機写真とアプリ画面のセット表示（03_reference-analysisでNature Remo分析から採用した見せ方） |
| CTAの有無 | なし |
| 次のセクションへつなぐ理由 | 機能理解が進んだ後は「実際の生活にどう馴染むか」を見せることで、購入後のイメージを具体化する |

## セクション6：生活空間での使用シーン（解決策の理解④）

| 項目 | 内容 |
|---|---|
| セクション名 | 部屋に置いたときの佇まい |
| 目的 | 「生活感が出ない」という価値を、実際の設置イメージで証明する |
| ユーザーへ伝える内容 | 在宅ワークのデスク周りに置いても違和感がないデザイン性 |
| 必要な見出し | 「置いているだけで、部屋が整う。」 |
| 必要な証拠・画像・数値 | 生活空間カット（デスク周りの使用シーン1パターンに絞る、03_reference-analysis方針） |
| CTAの有無 | なし |
| 次のセクションへつなぐ理由 | 機能・デザインへの納得が進んだところで、「本当に信頼できる商品か」という次の疑問に応えるため、実績紹介に接続する |

## セクション7：選ばれる理由・実績（信頼）

| 項目 | 内容 |
|---|---|
| セクション名 | 選ばれている理由 |
| 目的 | 第三者からの評価・実績を示し、購入への心理的ハードルを下げる |
| ユーザーへ伝える内容 | クラウドファンディングでの支援実績と、開発体制の背景 |
| 必要な見出し | 「512名が、先に選んだ理由。」 |
| 必要な証拠・画像・数値 | クラウドファンディング支援者512名、支援総額8,942,000円（出典：CF公式ページキャプチャを明記）、プロダクトデザイナー中心の開発体制（01/02資料準拠） |
| CTAの有無 | なし |
| 次のセクションへつなぐ理由 | 実績で信頼が高まっても、価格や使用条件への具体的な不安は残るため、不安解消のセクションに接続する |

## セクション8：不安の解消（不安解消①）

| 項目 | 内容 |
|---|---|
| セクション名 | よくある質問 |
| 目的 | 購入をためらう具体的な理由（価格・電気代・故障・部屋の広さ）に個別に答える |
| ユーザーへ伝える内容 | 電気代目安、フィルター交換目安、Wi-Fi非対応時の使用可否、適用畳数の正直な開示 |
| 必要な見出し | 「気になることは、先にお答えします。」 |
| 必要な証拠・画像・数値 | 電気代：標準運転で1時間約0.3円（月額目安約72円）／フィルター交換目安：2〜3ヶ月に1回／適用〜12畳（15畳以上は加湿力不足の可能性を明示）（01/02資料準拠） |
| CTAの有無 | なし |
| 次のセクションへつなぐ理由 | 個別の不安への回答だけでは足りない「購入リスクそのもの」への安心材料として、保証情報に接続する |

---

## セクション9：保証・スペック（不安解消②）

| 項目 | 内容 |
|---|---|
| セクション名 | 保証とスペック |
| 目的 | 購入リスクの低さと、商品仕様の正確な情報を提示する |
| ユーザーへ伝える内容 | 30日間返品保証・1年間メーカー保証、詳細スペック一覧 |
| 必要な見出し | 「安心して、試していただくために。」 |
| 必要な証拠・画像・数値 | 保証内容、スペック表（サイズ・重量・タンク容量・静音値・対応OS・Wi-Fi要件） |
| CTAの有無 | なし |
| 次のセクションへつなぐ理由 | 不安が解消された状態で、最後の行動を後押しするクロージングセクションへ接続する |

---

## セクション10：最終CTA・問い合わせ（行動）

| 項目 | 内容 |
|---|---|
| セクション名 | 購入・お問い合わせ |
| 目的 | ここまでの納得を行動に変換する。購入に至らない場合の受け皿も用意する |
| ユーザーへ伝える内容 | 価格の再提示、CTAへの誘導、購入に迷う人向けの問い合わせ導線 |
| 必要な見出し | 「今日から、部屋の空気を変える。」 |
| 必要な証拠・画像・数値 | 価格12,800円（税込）＋送料800円、保証内容の再掲 |
| CTAの有無 | あり（「NAGIを購入する」＋問い合わせフォームへのリンク） |
| 次のセクションへつなぐ理由 | 最終セクションのため次へは接続しない。フォームは「購入に進めない人の最後の受け皿」として機能させる |
