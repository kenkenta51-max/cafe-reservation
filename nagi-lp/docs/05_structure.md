## セクション4：主な特徴（解決策の理解②）

| 項目 | 内容 |
|---|---|
| セクション名 | 3つの特徴 |
| 目的 | 価値提案のうち「手間なく使える」という軸を、具体的な機能に分解して納得感を持たせる |
| ユーザーへ伝える内容 | ①スマホ遠隔・自動制御　②20dB以下の静音設計　③工具不要の抗菌タンク |
| 必要な見出し | 「暮らしに、静かに寄り添う3つの工夫。」 |
| 必要な証拠・画像・数値 | 各特徴のアイコン3点、静音値20dB以下、タンク容量2.5L・連続約20時間運転 |
| CTAの有無 | **あり（CTA②：セクション直後に独立したCTA帯を設置／「NAGIを購入する」）** |
| 次のセクションへつなぐ理由 | 「スマホ遠隔・自動制御」という機能は、実際の操作イメージが伴わないと伝わりにくいため、アプリ画面の紹介に接続する |

> **CTA②について**：機能を理解した直後は「行動してもよい」と感じる節目にあたるため、セクション本文の中ではなく、セクション4と5のあいだに独立したCTA帯として設置する。この段階で購入を決められるユーザーの離脱を防ぐ目的で、01_requirements「CTA設置方針」および04_design-system「CTA設計」に準拠。

> **特徴を3つに絞った理由**：当初は01_requirements §4「主な機能」の5項目をそのまま並べる想定だったが、次の2点を理由に本セクションでは3項目に絞る。**商品の機能自体が減るわけではなく、本セクションでカード表示しないという掲載上の判断である。**
>
> - **「ミニマルデザイン3色展開」を除外**：セクション3で本文とカラーバリエーション写真、セクション6で1セクション丸ごとを使ってデザイン性を訴求済みで、本セクションでは3度目の言及になる。デザインの良さは文言より写真で示すほうが強く、既にその形になっている。除外により本セクションが「手間なく使える工夫」に一本化され、ルールブック PART1-4「1セクション1メッセージ」が成立する
> - **「満水・空焚き自動停止」をセクション9へ移動**：02_strategy §4で「水漏れ等の故障不安」への回答と位置づけられており、不安解消フェーズであるセクション9の役割と一致する。移動先のスペック表に安全機能の記載がなかった穴も同時に埋まる
>
> 結果として3項目となり、3カラムグリッドの1行にちょうど収まる。5項目のままだとPC3カラムで2段目が2枚、タブレット2カラムでも2/2/1と余りが出ていた問題も解消する。

## セクション7：選ばれる理由・実績（信頼）

| 項目 | 内容 |
|---|---|
| セクション名 | 選ばれている理由 |
| 目的 | 第三者からの評価・実績を示し、購入への心理的ハードルを下げる |
| ユーザーへ伝える内容 | クラウドファンディングでの支援実績と、開発体制の背景 |
| 必要な見出し | 「512名が、先に選んだ理由。」 |
| 必要な証拠・画像・数値 | クラウドファンディング支援者512名、支援総額8,942,000円（出典：CF公式ページキャプチャを明記）、プロダクトデザイナー中心の開発体制（01/02資料準拠） |
| CTAの有無 | **あり（CTA③：セクション直後に独立したCTA帯を設置／「NAGIを購入する」）** |
| 次のセクションへつなぐ理由 | 実績で信頼が高まっても、価格や使用条件への具体的な不安は残るため、不安解消のセクションに接続する |

> **CTA③について**：実績によって信頼が高まった直後は、購入判断が最も進みやすい節目にあたる。セクション7と8のあいだに独立したCTA帯として設置し、返品保証への言及を添えて心理的ハードルを下げる。

## セクション8：不安の解消（不安解消①）

| 項目 | 内容 |
|---|---|
| セクション名 | よくある質問 |
| 目的 | 購入をためらう具体的な理由（価格・電気代・故障・部屋の広さ）に個別に答える |
| ユーザーへ伝える内容 | 電気代目安、フィルター交換目安、Wi-Fi非対応時の使用可否、適用畳数の正直な開示 |
| 必要な見出し | 「気になることは、先にお答えします。」 |
| 必要な証拠・画像・数値 | 電気代：標準運転で1時間約0.3円（月額目安約72円）／フィルター交換目安：2〜3ヶ月に1回／適用〜12畳（15畳以上は加湿力不足の可能性を明示）（01/02資料準拠） |
| CTAの有無 | なし |
| 次のセクションへつなぐ理由 | 個別の不安への回答だけでは足りない「購入リスクそのもの」への安心材料として、保証情報に接続する |

## セクション9：保証・スペック（不安解消②）

| 項目 | 内容 |
|---|---|
| セクション名 | 保証とスペック |
| 目的 | 購入リスクの低さと、商品仕様の正確な情報を提示する |
| ユーザーへ伝える内容 | 30日間返品保証・1年間メーカー保証、**満水・空焚き自動停止の安全機能**、詳細スペック一覧 |
| 必要な見出し | 「安心して、試していただくために。」 |
| 必要な証拠・画像・数値 | 保証内容、**安全機能（満水・空焚き自動停止）**、スペック表（サイズ・重量・タンク容量・静音値・対応OS・Wi-Fi要件） |
| CTAの有無 | なし |
| 次のセクションへつなぐ理由 | 不安が解消された状態で、最後の行動を後押しするクロージングセクションへ接続する |

> **安全機能をここに置く理由**：「満水・空焚きになると自動で止まる安全設計」はセクション4から移動したもの。02_strategy §4で「水漏れ等の故障不安」への解消手段と位置づけられており、機能紹介ではなく不安解消のフェーズで示すほうが心理フローに合う。保証（返品・メーカー保証）と並べることで「万が一への備え」として一体で読ませる。

## CTA配置方針（全4箇所）

| No. | 位置 | 設置形式 | 狙い |
|---|---|---|---|
| CTA① | ヒーロー | セクション内 | 検討済みで訪問したユーザーを最短で購入へ導く |
| CTA② | 主な特徴の直後 | 独立したCTA帯 | 機能への納得が生まれた節目で再提示する |
| CTA③ | 選ばれる理由・実績の直後 | 独立したCTA帯 | 信頼が高まった直後、購入判断が最も進む節目で再提示する |
| CTA④ | 最終CTA・問い合わせ | セクション内 | クロージング。購入に進めない人向けにフォームを併設 |

**補足事項**

- 文言は全4箇所とも「NAGIを購入する」で統一し、表記ゆれを作らない（04_design-system §5）
- 遷移先は自社ECサイト（Shopify）の商品購入ページで統一
- スマートフォンでは上記4箇所に加え、画面下部に固定CTA（sticky）を表示する（04_design-system §5）
- セクション2・3・5・6・8・9にはCTAを置かない。ルールブック PART8-3「全セクション後に機械的に置かない／訪問者が行動してもよいと感じる節目へ配置する」に従い、悩みの提示中や機能説明の途中では押さない
- 問い合わせフォームの送信ボタンは補助CTAとして扱い、主要CTAより弱く表示する（ルールブック PART8-1）
