## 1. カラー

### ブランドカラー（確定）

| 役割 | カラー名 | HEX | 使用比率目安 |
|---|---|---|---|
| メインカラー | ミストグレー | `#6B7280` | 約20%（**罫線・図解などの非テキスト要素に限定**） |
| キーカラー | ディープグリーン | `#2F4A3E` | 約10%（CTA・アクセントに集中使用） |
| サブカラー | サンドベージュ | `#C9BBA0` | 約10%（写真背景・小物との調和、罫線） |
| ベースカラー | オフホワイト | `#FAFAF8` | 約60%（背景の大半） |
| テキストカラー | ダークグレー | `#23272A` | 本文・見出し |
| 補助テキスト | ライトグレー | `#5F6B66` | キャプション・注釈・リード |

［事実］ミストグレー・ディープグリーン・サンドベージュ・オフホワイト・ダークグレーのHEXコードは、ヒアリングシート05にて正式決定済み。

［提案］配色比率はベース60〜70%・メイン20%・アクセント10%というルールブック標準に準拠。BALMUDA・cado分析で確認した「無彩色中心＋主張は最小限」という原則を反映。

### 派生色（実装時に算出）

| 用途 | HEX | 算出根拠 |
|---|---|---|
| 強調セクションの地 | `#F2EDE3` | サンドベージュをベースカラー側へ寄せた淡色。章の変化を背景で示すために使用 |
| CTAホバー | `#3A5C4D` | ディープグリーンの明度+10%（§5の指定に基づく） |
| ヘアライン | `#E2E1DC` | ベースカラーに対する罫線 |

新規の色相は増やさず、上記6色から算出した値のみを使う。

### コントラスト

- 本文文字と背景のコントラスト比は**4.5:1以上**を確保する（ルールブック基準）
- 大きな文字は**3:1以上**
- ディープグリーンの背景に白文字を乗せる場合はコントラスト比を個別に確認する

**実測値（2026年7月31日、`src/index.html` にて計測）**

| 組み合わせ | 比率 | 判定 |
|---|---|---|
| ダークグレー `#23272A` × オフホワイト地 | 14.40:1 | 適合 |
| 補助テキスト `#5F6B66` × ベージュ地 `#F2EDE3` | 4.76:1 | 適合 |
| 白文字 × ディープグリーン地 | 9.68:1 | 適合 |
| CTAボタン（白文字 × `#2F4A3E`） | 9.68:1 | 適合 |

### 【2026年7月31日 改訂】補助テキスト色の変更

補助テキストを **ライトグレー `#8A9490` → `#5F6B66`** に変更した。

**変更理由**：当初指定の `#8A9490` は、キャプションサイズ（13px）で使用した場合のコントラスト比が
**ベージュ地で2.68:1**、オフホワイト地でも3.0:1程度にとどまり、**本節が自ら定める
「本文4.5:1以上」という基準を満たしていなかった**ため。ルールブック PART5-5「淡い背景に淡い文字を置く」
および PART14-1 の禁止事項にも該当する。

色相は変えず明度のみを下げているため、トーン&マナーへの影響はない。変更後は
ベージュ地で4.76:1、オフホワイト地で5.35:1となり基準を満たす。

あわせて、**メインカラーのミストグレー `#6B7280` はテキストへの使用を取りやめた**。
ベージュ地で4.20:1と本文基準に届かないため、罫線・図解などの非テキスト要素に限定する。

## 2. タイポグラフィ

| 要素 | PCサイズ | SPサイズ | ウェイト |
|---|---|---|---|
| H1（ヒーローキャッチ） | 56px | 36px | Bold |
| H2（セクション見出し） | 36px | 26px | Bold |
| H3（小見出し） | 22px | 18px | Medium |
| 本文 | 16px | 15px | Regular |
| キャプション・注釈 | 13px | 12px | Regular |

［提案］ルールブック基準（H1: PC48-72px／SP32-44px）の範囲内で、BALMUDA分析の「文字量が少ない分、大きめのサイズで余白を活かす」方針を踏まえてやや大きめのH1（56px）を採用。

**フォント選定方針**：見出しに柔らかさとモダンさを両立する角のないゴシック体、本文に可読性の高いゴシック体を使用（提案：見出し=Noto Sans JP Bold相当、本文=Noto Sans JP Regular相当）。

**【2026年7月31日 申し送り】** STEP7の初期デザインでは、制作環境の制約により Noto Sans JP を
読み込めず、日本語システムフォントスタック（`Hiragino Kaku Gothic ProN` → `Hiragino Sans` →
`Noto Sans JP` → `Yu Gothic`）で実装している。**STEP8（全体実装）までに Noto Sans JP を
self-host した woff2 へ差し替える**こととし、クライアント承認済み。差し替え時に字面が
わずかに変わるため、行間・字送りの再確認が必要。

## 3. レイアウト・余白

| 項目 | 数値 |
|---|---|
| コンテンツ最大幅 | 1140px |
| セクション余白（標準） | 96px（PC）／64px（SP） |
| セクション余白（強調セクション：ヒーロー・CTA） | 140px（PC）／80px（SP） |
| 要素間の余白スケール | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96px |
| グリッド | 1カラム基本。特徴紹介セクションのみ3カラムグリッド（SPでは1カラムに変化） |

［提案］ルールブック標準の余白スケールをそのまま採用。BALMUDA分析の「大きな余白で1メッセージずつ見せる」原則を、情報量の多いNature Remo型のセクション（特徴紹介・スペック表）よりゆったり目に設定。

## 4. 写真・イラストの方向性

| 種別 | 方針 |
|---|---|
| 商品単体写真 | 白〜オフホワイト背景、斜め・やや見下ろす角度（BALMUDA分析を採用） |
| 商品単体写真の扱い（暫定） | **現素材は背景が純白ではなくベース地に溶け込まないため、写真パネルとして配置している**（角丸4px）。背景透過素材が支給され次第、地に製品が浮く配置へ差し替える。2026年7月31日、クライアント承認済み |
| 生活空間カット | デスク周りの1シーンに絞る（cado分析の「暮らしに溶け込む」を採用しつつ、Nature Remoのような複数ペルソナ展開はしない） |
| アプリ画面 | 実機と並べて配置（Nature Remo分析を採用） |
| 色調 | ブランドカラーのグレー・グリーン・ベージュと調和する自然光の写真を基本とする |
