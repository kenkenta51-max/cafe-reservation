## 1. カラー

### ブランドカラー（2026年8月2日改訂）

| 役割 | カラー名 | HEX | 使用比率目安 |
|---|---|---|---|
| ベースカラー | ウォームホワイト | `#F7F2EA` | 約60%（背景の大半） |
| メインカラー | ミストグレー | `#6B7280` | 約15%（罫線・図解専用、本文には使用しない） |
| キーカラー | ウォールナットブラウン | `#4A362A` | 約12%（CTA・アクセントに集中使用） |
| サブカラー | 真鍮ベージュ | `#B69B6E` | 約8%（罫線・数値の縁取りなど、控えめな高級感の演出） |
| 強み地（セクション背景） | サンドベージュ地 | `#F2EDE3` | セクション背景の切り替えのみ |
| テキストカラー | ウォームブラック | `#2B2420` | 本文・見出し |
| 補助テキスト | 補助グレー | `#5F6B66` | キャプション・注釈（4.76:1、旧`#8A9490`から改訂済み） |

［提案・2026年8月2日改訂］お客様より「シンプルすぎる／もっと洗練された雰囲気にしたい」「黒でなくてよいが、リビング・寝室に置くものなので温かみ・木のイメージを全体に持たせたい」という要望を受け、グレー×ディープグリーンを基調としたクールな配色から、**ウォールナットブラウン×真鍮ベージュ**を基調とした温かみのある配色へ変更。パナソニックBeauty PREMIUM（美容家電LP）を参考に、「黒による高級感」ではなく「質感・余白・金の差し色」による洗練度の出し方を採用した。

**変更の理由**：
- 旧キーカラーのディープグリーン`#2F4A3E`は、参考サイト分析（BALMUDA・cado）を踏まえた「無彩色中心＋控えめなアクセント」という原則には合っていたが、お客様の生活空間（リビング・寝室）との親和性という点で「木・温かみ」を感じさせる要素が不足していた
- 黒背景は重厚感が出る一方、NAGIのターゲット（インテリアに馴染ませたい層）にはやや強すぎるため不採用とし、ウォールナットブラウンで代替

［事実］LP構成（05_structure.md）・情報量・余白の考え方は変更していません。今回の改訂は配色・写真トーンのみが対象です。

### コントラスト
- 本文文字と背景のコントラスト比は**4.5:1以上**を確保する（ルールブック基準）
- ウォールナットブラウンの背景に白文字を乗せる場合はコントラスト比を個別に確認する
- 真鍮ベージュ`#B69B6E`は本文への使用不可（コントラスト不足のため罫線・装飾専用とする）

**フォント選定方針**：見出しに柔らかさとモダンさを両立する角のないゴシック体、本文に可読性の高いゴシック体を使用（提案：見出し=Noto Sans JP Bold相当、本文=Noto Sans JP Regular相当）。

## 4. 写真・イラストの方向性（2026年8月2日改訂）

| 種別 | 方針 |
|---|---|
| 商品単体写真 | ウォームホワイト〜木目の台座を感じさせる背景、斜め・やや見下ろす角度（BALMUDA分析を採用しつつ、背景に木目テクスチャを軽く添える） |
| 生活空間カット | リビングまたは寝室の1シーンに絞る（cado分析の「暮らしに溶け込む」を採用）。木製家具（ウォールナット・オーク調）、間接照明、観葉植物、布ものの質感を添え、温かみを演出する |
| アプリ画面 | 実機と並べて配置（Nature Remo分析を採用）。UIのアクセントカラーもウォールナットブラウンに統一 |
| 色調 | 電球色寄りの暖色照明を基本とし、真っ白な無機質な光は避ける。パナソニックBeauty PREMIUM分析で確認した「陰影のある温かい光」を弱めに採用 |
| 装飾 | 金属的なキラキラ演出（粒子・光沢エフェクト）は不採用。真鍮色の細い罫線程度の控えめな高級感にとどめる |

［事実］商品写真・生活空間カットはChatGPTで再生成する前提。本ドキュメントのトーン指定を画像生成プロンプトに反映する。
