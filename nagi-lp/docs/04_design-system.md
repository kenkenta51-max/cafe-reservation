## 1. カラー

### ブランドカラー（確定）

| 役割 | カラー名 | HEX | 使用比率目安 |
|---|---|---|---|
| メインカラー | ミストグレー | `#6B7280` | 約20% |
| キーカラー | ディープグリーン | `#2F4A3E` | 約10%（CTA・アクセントに集中使用） |
| サブカラー | サンドベージュ | `#C9BBA0` | 約10%（写真背景・小物との調和） |
| ベースカラー | オフホワイト | `#FAFAF8` | 約60%（背景の大半） |
| テキストカラー | ダークグレー | `#23272A` | 本文・見出し |
| 補助テキスト | ライトグレー | `#8A9490` | キャプション・注釈 |

［事実］HEXコードはヒアリングシート05にて正式決定済み。

［提案］配色比率はベース60〜70%・メイン20%・アクセント10%というルールブック標準に準拠。BALMUDA・cado分析で確認した「無彩色中心＋主張は最小限」という原則を反映。

### コントラスト
- 本文文字と背景のコントラスト比は**4.5:1以上**を確保する（ルールブック基準）
- ディープグリーンの背景に白文字を乗せる場合はコントラスト比を個別に確認する

## 2. タイポグラフィ

| 要素 | PCサイズ | SPサイズ | ウェイト |
|---|---|---|---|
| H1（ヒーローキャッチ） | 56px | 36px | Bold |
| H2（セクション見出し） | 36px | 26px | Bold |
| H3（小見出し） | 22px | 18px | Medium |
| 本文 | 16px | 15px | Regular |
| キャプション・注釈 | 13px | 12px | Regular |

［提案］ルールブック基準（H1: PC48-72px／SP32-44px）の範囲内で、BALMUDA分析の「文字量が少ない分、大きめのサイズで余白を活かす」方針を踏まえてやや大きめのH1（56px）を採用。

**フォント選定方針**：見出しに柔らかさとモダンさを両立する角のないゴシック体、本文に可読性の高いゴシック体を使用（提案：見出し=Noto Sans JP Bold相当、本文=Noto Sans JP Regular相当）。

## 3. レイアウト・余白

| 項目 | 数値 |
|---|---|
| コンテンツ最大幅 | 1140px |
| セクション余白（標準） | 96px（PC）／64px（SP） |
| セクション余白（強調セクション：ヒーロー・CTA） | 140px（PC）／80px（SP） |
| 要素間の余白スケール | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96px |
| グリッド | 1カラム基本。特徴紹介セクションのみ3カラムグリッド（SPでは1カラムに変化） |

［提案］ルールブック標準の余白スケールをそのまま採用。BALMUDA分析の「大きな余白で1メッセージずつ見せる」原則を、情報量の多いNature Remo型のセクション（特徴紹介・スペック表）よりゆったり目に設定。

## 4. 写真・イラストの方向性

| 種別 | 方針 |
|---|---|
| 商品単体写真 | 白〜オフホワイト背景、斜め・やや見下ろす角度（BALMUDA分析を採用） |
| 生活空間カット | デスク周りの1シーンに絞る（cado分析の「暮らしに溶け込む」を採用しつつ、Nature Remoのような複数ペルソナ展開はしない） |
| アプリ画面 | 実機と並べて配置（Nature Remo分析を採用） |
| 色調 | ブランドカラーのグレー・グリーン・ベージュと調和する自然光の写真を基本とする |

## 5. CTA設計

| 項目 | 内容 |
|---|---|
| 文言 | 「NAGIを購入する」で統一（表記ゆれを作らない） |
| 配置数 | 4箇所（ヒーロー／特徴紹介後／信頼情報後／ページ末尾） |
| ボタンサイズ | 高さ52px、タップ領域は最低44px確保（ルールブック基準） |
| 色 | ディープグリーン（`#2F4A3E`）背景に白文字。ホバー時は明度を10%上げる |
| スマホでの挙動 | 画面下部に固定表示（sticky CTA）とする（Nature Remo分析を採用） |

## 6. アニメーション

- ページ内の要素はスクロール時にフェードイン程度の控えめな演出（150〜300ms）にとどめる
- BALMUDAのような動画中心の演出は今回の予算・素材状況に合わないため採用しない
- ボタンのホバー・タップ時の反応は200ms程度で簡潔に

## 8. このデザインシステムの位置づけ

このドキュメントは「共通デザインルールブック」の数値基準を土台に、NAGI案件専用の値へ落とし込んだものです。矛盾が生じた場合は、優先順位に従い**共通デザインルールブック側を正**とします（案件固有ルールがルールブックの範囲を逸脱する場合は、要件定義・訴求設計の内容を再確認してください）。
