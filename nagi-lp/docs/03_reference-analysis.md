## サイト②：Nature Remo 3

**URL**: https://shop.nature.global/products/nature-remo-3

| 項目 | 内容 |
|---|---|
| サイトの目的とターゲット | ［確認］スマートホーム初心者〜中級者。EC直販での購入（Shopify）が目的 |
| ファーストビューの構成 | ［確認］商品画像ギャラリー（サムネイル切替式）＋商品名＋レビュー件数（20件）＋価格＋数量選択＋購入ボタンが1画面に集約。受賞バッジ（累計販売台数・Amazonレビュー1位・iF Design Award）を画像上部に3つ横並びで配置 |
| セクション順 | ［確認］①ヒーロー（ギャラリー＋価格＋CTA）→②利用シーン訴求（5パターンのペルソナ別スライド：子育て・時短・ペット・在宅・帰宅時）→③オートメーション機能の説明（アイコン4分割）→④対応外部機器の紹介→⑤スマートスピーカー連携→⑥旧家電との互換性→⑦セットアップ手順（3ステップ）→⑧ユーザーインタビュー（動画）→⑨カスタマーレビュー→⑩スペック表→⑪関連製品→⑫ニュースレター登録→⑬フッター |
| レイアウトと最大幅 | ［推定］1カラム、コンテンツ最大幅は約1100〜1200px。ECテンプレート（Shopify）ベースのため、商品情報エリアは2カラム（画像＋購入パネル）、以降は1カラムに戻る構成 |
| 余白の取り方 | ［推定］セクション間の余白は中〜大（96〜120px相当）。機能説明が多いため、BALMUDAよりやや情報密度が高い |
| フォントサイズと見出し階層 | ［推定］h2相当32〜40px、本文14〜16px。機能数が多いため文字はやや小さめで情報量を確保 |
| 配色と背景の使い分け | ［確認/推定］白背景中心、アクセントに黄色（ブランドカラー）を小面積で使用。セクションごとに背景色（白／薄いグレー）を交互に切り替えて区切りを作る |
| 写真・イラストの方向性 | ［確認］実機写真に加え、イラスト・アイコンを多用（オートメーション条件の説明など）。ペルソナ別のシチュエーション写真を多用 |
| CTAの配置・文言・色 | ［確認］ファーストビューの購入ボタンが常時表示される設計（価格・数量と一体化）。文言は「購入する」に相当する直接的な表現 |
| スマホ表示の特徴 | ［推定］画像ギャラリーは横スワイプ式に変化、ペルソナ別スライドも横スワイプ、購入ボタンはスマホでは画面下部に固定表示（sticky CTA）と推定 |
| 採用する点 | ①アプリ画面と実機をセットで見せる構成 ②受賞歴・販売実績を数字でシンプルに提示する手法 ③スマホでの固定CTA |
| 採用しない点／理由 | ペルソナ別に5パターンも訴求を作るのは、NAGIの単一ターゲット戦略（30代前半・在宅ワーク層に絞る方針）と矛盾するため、1〜2パターンに絞って採用する |

## サイト③：cado

**URL**: https://cado.com/

| 項目 | 内容 |
|---|---|
| サイトの目的とターゲット | ［確認］複数の空気家電を展開するブランドとして、まずブランド・製品ラインナップを認知させることが目的。個別商品より「空気をデザインする」という企業コンセプトが前面に出ている |
| ファーストビューの構成 | ［確認］トップページは新商品・キャンペーンのスライドショー形式（単一商品LPというより複数製品のカタログ的構成） |
| セクション順 | ［確認］①新着製品スライド→②コンテンツバナー一覧（各製品の紹介記事への導線）→③メイン製品カテゴリ一覧→④その他製品→⑤ギフトパッケージ→⑥人気製品ランキング→⑦ブランドストーリー（About/The Room等）→⑧新着ニュース→⑨サポート導線→⑩フッター |
| レイアウトと最大幅 | ［推定］グリッドレイアウトを多用（商品カードが並ぶ形式）。最大幅は約1280px程度 |
| 余白の取り方 | ［推定］商品点数が多いため、BALMUDA・Nature Remoに比べ余白は控えめ（64〜80px相当）で情報密度が高い |
| フォントサイズと見出し階層 | ［推定］見出しは28〜36px程度と控えめ。カード型レイアウトのため見出しサイズを抑えて統一感を出している |
| 配色と背景の使い分け | ［確認/推定］白背景中心、写真の彩度・質感で製品の高級感を出す設計。装飾的な配色はほぼ使わない |
| 写真・イラストの方向性 | ［確認］生活空間に置いた実例カットを多用（「The Room」という専用コーナーまである）。単体商品写真より「暮らしに溶け込む」写真を重視 |
| CTAの配置・文言・色 | ［確認］「詳しく見る」という控えめな文言を各カードに配置。強い購買訴求より情報への誘導が中心 |
| スマホ表示の特徴 | ［推定］カードグリッドは2列→1列に変化する一般的なレスポンシブパターンと推定 |
| 採用する点 | 「暮らしに溶け込む」生活空間カットの使い方、落ち着いたトーンのコピー、装飾を抑えた配色 |
| 採用しない点／理由 | 複数製品を並べるカタログ型の構成は、単一商品を売るNAGIのLPには不要なため不採用。「詳しく見る」的な控えめなCTAではなく、NAGIは購入意欲の高いユーザーに明確な行動を促す必要があるため、CTA文言はより直接的な「NAGIを購入する」を維持する |

## 総合：NAGI LPへのセクション構成方針（提案）

［提案］3サイトの分析を踏まえ、NAGIのLPは以下のセクション順を推奨する。

1. ヒーロー（製品ビジュアル＋短いキャッチコピー＋CTA）※BALMUDA型
2. 価値提案（デザイン×手間のなさ）
3. 悩みの提示と共感
4. 主な特徴（5つ、アイコン＋簡潔な説明）※Nature Remo型のアイコン整理を参考
5. アプリ連携の見せ方（実機×アプリ画面）※Nature Remo型
6. 生活空間での使用シーン（1〜2パターンに絞る）※cado型の「暮らしに溶け込む」写真
7. 選ばれる理由・実績（CF支援実績）
8. 不安の解消（保証・FAQ）
9. スペック表
10. 最終CTA＋問い合わせフォーム
