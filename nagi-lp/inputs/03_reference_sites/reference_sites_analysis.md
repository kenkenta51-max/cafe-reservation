# 参考サイト分析｜NAGI（凪）スマート加湿器 LP

> 「LP専用 共通デザインルールブック」PART17-1・手順書STEP4に基づき、
> 参考サイトから見た目をそのまま模倣するのではなく、実装可能なルールとして原則を抽出する。

## 参考サイト①：BALMUDA「Rain」

- **URL**: https://www.balmuda.com/jp/rain/
- **選定理由**: 加湿器という同一カテゴリで、機能とデザイン性を両立させる訴求構成の参考になる

### 抽出した原則

| 項目 | 内容 |
|---|---|
| サイトの目的・ターゲット | 高価格帯の加湿器を検討する、デザインにこだわりのある層への訴求 |
| ファーストビュー | 製品単体を大きく見せ、キャッチコピーは短文。機能訴求より世界観訴求が先 |
| セクション順 | デザイン→適切な湿度（機能）→使用体験→スペック→購入 の順で、感情→機能→安心の流れ |
| レイアウト・余白 | 1カラム構成で余白を大きく取り、1セクション1メッセージが徹底されている |
| 配色 | 白・グレーの無彩色中心で製品写真を主役にし、装飾色をほぼ使わない |
| 写真の方向性 | 製品を斜め・低い視点から撮影し、素材感（質感）が伝わるライティング |
| CTAの配置・文言 | 各セクション末に控えめに配置。「購入」「販売店を探す」など具体的な行動文言 |

### 採用する点
- 1セクション1メッセージの徹底
- 製品写真を主役にし、テキストを最小限にする余白の使い方

### 採用しない点
- 高価格帯特有の長い世界観訴求（NAGIは価格帯・訴求設計が異なるため、機能訴求をやや前に出す）

## 参考サイト②：Nature Remo（スマートリモコン）

- **URL**: https://nature.global/ ／ https://shop.nature.global/products/nature-remo-3
- **選定理由**: スマホアプリ連携を訴求の中心に据えるIoT機器として、NAGIのアプリ連携訴求の参考になる

### 抽出した原則

| 項目 | 内容 |
|---|---|
| サイトの目的・ターゲット | スマートホーム初心者〜中級者。「難しそう」という不安の解消が重要な訴求軸 |
| ファーストビュー | 「スマホから家電を操作できる」という価値を一文で明示し、アプリ画面と実機を並べて見せる |
| セクション順 | 悩み（リモコンの不便さ）→解決（スマホ操作）→対応機器の幅広さ→受賞歴による信頼→購入 |
| 配色・デザインコンセプト | 「存在感がない、考えさせない」という明確なデザインコンセプトを持ち、生活に溶け込む配色 |
| 信頼要素の見せ方 | 受賞歴（iF Design Award等）や販売台数を数字で明示し、根拠を短く添える |
| アプリ画面の見せ方 | 実機とスマホ画面をセットで見せ、「操作の簡単さ」を視覚的に伝える |

### 採用する点
- アプリ画面と実機をセットで見せる構成（NAGIのスマホ管理機能の訴求に直接応用できる）
- 受賞歴・販売実績など根拠を数字で簡潔に見せる手法

### 採用しない点
- 「存在感がない」デザインコンセプトはNGテーマ（NAGIは「主張しすぎないが、置いて美しい」という異なる方向性のため、そのまま流用しない）

## 参考サイト③：cado（空気清浄機・加湿器ブランド）

- **URL**: https://cado.com/
- **選定理由**: 「空気をデザインする」という一貫したコンセプトを掲げる国内デザイン家電ブランドで、NAGIのブランドトーンに最も近い

### 抽出した原則

| 項目 | 内容 |
|---|---|
| サイトの目的・ターゲット | インテリア・空気環境の両方にこだわる層。価格より世界観の一貫性を重視する購買層 |
| デザインコンセプトの一貫性 | 「空気をデザインする」というコンセプトを全商品ページで一貫させ、機能訴求より先にブランドの一貫性を提示 |
| 製品ラインナップの見せ方 | 空気清浄機・加湿器・除湿機など複数製品を、同じデザイン言語（トーン&マナー）で統一して見せる |
| 写真・素材感 | 生活空間に置いた実例カットを多用し、「モノ単体」より「暮らしに溶け込む様子」を重視 |
| 訴求のトーン | 過度なセール文言を避け、落ち着いたコピーライティングで上質さを演出 |

### 採用する点
- 「暮らしに溶け込む様子」を見せる生活空間カットの使い方
- 落ち着いたトーンのコピーライティング（誇大表現を避ける方針は訴求設計・原稿作成時にも徹底する）

### 採用しない点
- 複数製品ラインの統一デザインという前提はNAGI（単一商品LP）には該当しないため、該当部分は不採用

## 総合：NAGI LPへの反映方針

| デザイン要素 | 反映方針 |
|---|---|
| セクション構成 | BALMUDA型の「感情→機能→安心→購入」の流れを基本とする |
| アプリ訴求 | Nature Remo型の「実機×アプリ画面」のセット表示を採用 |
| 世界観・写真 | cado型の「暮らしに溶け込む」生活空間カットを中心に据える |
| 配色 | 3サイトに共通する無彩色中心の配色を踏襲しつつ、ヒアリングシートの希望色（グレー×ディープグリーン）を軸にする |
| 避ける表現 | 過度なセールス文言、誇張された効能表現（3サイトとも避けている） |
