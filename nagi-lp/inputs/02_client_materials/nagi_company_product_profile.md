## 2. 商品資料｜スマート加湿器「NAGI（凪）」

### 2-1. 商品概要

超音波式のコンパクトなスマート加湿器。専用アプリでの遠隔・自動制御、20dB以下の静音設計、工具不要で分解できる抗菌タンクを特徴とし、「生活感を出さずにインテリアに馴染む加湿器」をコンセプトに開発された。

### 2-2. スペック

| 項目 | 内容 |
|---|---|
| 商品名 | NAGI（凪） スマート加湿器 |
| 価格 | 12,800円（税込）／送料800円（全国一律） |
| サイズ | W140 × D140 × H280 mm |
| 重量 | 約1.1kg（水を入れない状態） |
| タンク容量 | 2.5L（満水で約20時間連続運転） |
| 加湿方式 | 超音波式 |
| 適用畳数 | 〜12畳（15畳以上は加湿力が不足する場合あり） |
| 静音性 | 20dB以下（最小運転時） |
| 対応通信 | Wi-Fi 2.4GHz帯 |
| 対応アプリ | iOS 15以降／Android 11以降 |
| カラー展開 | ミストグレー／ディープグリーン／サンドベージュ の3色 |
| 同梱物 | 本体、替えフィルター2個、電源アダプター、簡易説明書 |
| 保証 | 購入後30日間の返品保証、1年間メーカー保証 |

### 2-3. 主な特徴

1. **スマホでの遠隔・自動制御**：専用アプリで湿度・稼働スケジュールを管理。外出先からも操作可能
2. **20dB以下の静音設計**：就寝時や在宅ワーク中でも気にならない静かさ
3. **工具不要の抗菌タンク**：ワンタッチで分解でき、手入れの手間を軽減
4. **ミニマルデザイン（3色展開）**：生活感の出やすい家電デザインを避け、インテリアに馴染む造形
5. **満水・空焚き自動停止**：安全機能として搭載

### 2-4. 価値提案（訴求の核）

> 「デザインを妥協せず、手間なく最適な湿度を保てる」

- ターゲットの悩み：市販の加湿器は生活感が出てしまう／手入れが面倒で続かない
- 提供する解決：見た目を損なわず、スマホ一つで管理が完結する加湿器

### 2-5. おすすめできないケース（正直な情報開示）

- 部屋の広さが15畳を超える場合は加湿力が不足する可能性がある
- Wi-Fi環境（2.4GHz帯）がない場合、アプリ連携機能は使用できない（加湿器としての基本機能は使用可）

### 2-6. 実績・信頼情報

- クラウドファンディングで支援者512名を獲得（支援総額はお客様確認待ち）

- グッドデザイン賞への応募を検討中（応募・受賞は未確定）
